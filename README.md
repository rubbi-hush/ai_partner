# ai_partner

#### 介绍
用python语言实现的一个类似于deepseek的对话式AI智能伴侣。

#### 软件架构
Python,streamlit,deepseek API


#### 安装教程

1.  用pycharm打开05.ai_partner_3文件
2.  配置系统环境变量，DEEPSEEK_API_KEY的值设置为官方开放的deepseek API KEY
3.  在终端中下载相关python包，比如：pip install streamlit等。
4.  在终端中输入命令 streamlit run .\05.ai_partner_3.py

#### 使用说明

 需要在deepseek官方开放平台中充值并生成自己的API密钥
